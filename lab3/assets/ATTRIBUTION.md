# Происхождение ресурсов

Шесть PNG созданы для этой работы алгоритмом `tools/generate_textures.py`.
Сторонние фотографии и текстуры не использованы. Файлы распространяются
на условиях лицензии проекта. Генератор использует Pillow только при ручной
регенерации; графическое приложение загружает готовые PNG через stb_image.

`third_party/stb/stb_image.h`: https://github.com/nothings/stb
commit **003501f6d7a8668ce8b6d875e34dd97ad0d5d5b5**.
Исходный header включён без изменений. Лицензия MIT/public domain сохранена
в `third_party/stb/LICENSE`, также присутствует в конце header.
`STB_IMAGE_IMPLEMENTATION` определён только в `source/image.cpp`.

Соглашение: PNG хранится верхней строкой вперёд; decoder один раз переворачивает
строки. Поэтому v=0 соответствует низу исходного изображения, v=1 — верху.
Боковина: u=1-angleCCW/(2*pi), v=(y+1)/2. U направлена по часовой стрелке,
чтобы текст читался снаружи. Крышки имеют собственные нормали и
плоскую развёртку, верхняя использует инверсию z для ориентации снаружи.

Albedo и художественная голубая emissive-карта — sRGB; specular mask и black —
линейные UNORM. Свет и эмиссия складываются в линейном пространстве.
Для sRGB swapchain преобразование выполняет Vulkan; для UNORM используется
существующая `displayColor`, без двойного кодирования.
