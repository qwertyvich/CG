# Показ базы и дополнительного задания

Запустите `lab4\tools\run.cmd`. Демо-кнопки **полностью сбрасывают сцену**; сначала нажимайте нужную сцену, потом меняйте параметры. `Reset shadows` сбрасывает только shadow settings. Если картинка не совпадает с ожиданиями, начните с демо заново. В обычных demo цилиндры статичны. Все значения ниже — для демонстрации, а не требование к точности физической модели.
