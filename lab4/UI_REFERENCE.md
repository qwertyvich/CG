# Справочник интерфейса

Все подписи ниже соответствуют `source/controls.cpp`. Мышью откройте заголовок секции, перетаскивайте значения/ползунки, выбирайте объект/материал в списках. XYZ означает три компонента в порядке X, Y, Z. Цвета и интенсивности задаются в линейном пространстве, а вывод учитывает sRGB.

## Готовые сцены и общие кнопки

| Подпись | Перевод / определение | Что меняется и область действия |
|---|---|---|
| `Directional shadow demo` | Пример тени солнца | Полный сброс сцены: два цилиндра на полу, солнце и слабый ambient, point/spot выключены |
| `Spot shadow demo` | Пример тени прожектора | Полный сброс: солнце выключено, один spot включён, ambient=0.035; маркер и конус видны |
| `Combined shadows` | Обе тени | Полный сброс: солнце+spot, две отдельные карты одновременно |
| `Sampling demo` | Пример sampling из ЛР3 | Полный сброс; на первом цилиндре меняется выборка albedo, тени работают через тот же lighting.glsl |
| `Emission demo` | Пример эмиссии из ЛР3 | Полный сброс; Panels на первом цилиндре, все источники выключены, эмиссия остаётся |
| `Specular demo` | Пример specular mask из ЛР3 | Полный сброс; Panels, эмиссия=0, specular первого цилиндра сравнивается со вторым |
| `Reset scene` | Сброс всей сцены | Камера, модели, время, материалы, списки света и shadows возвращаются к начальной сцене солнца |
| `All lights off` | Выключить весь свет (ЛР3) | Отключает ambient, directional и флаги всех point/spot. Не меняет emissive карт и настройки shadow toggles |
| `Restore lights` | Включить свет (ЛР3) | Включает ambient/directional и все существующие point/spot. Не восстанавливает удалённые источники и не сбрасывает интенсивности |

## Shadows — новое в ЛР4

| Подпись | Перевод / определение | Что меняется и область действия |
|---|---|---|
| `Directional shadows` | Тени направленного источника | Только visibility солнца. При Off солнце продолжает освещать, но препятствия не закрывают его прямой вклад. При выключенном солнце карта не перерисовывается |
| `Shadow half extent` | Половина ширины и высоты покрытия | Ортографическая карта солнца покрывает квадрат 2h×2h единиц мира. Диапазон 0.5–30, default 7. Не размер текстуры и не яркость света; spot не затрагивает |
| `Constant depth bias` | Постоянная часть смещения глубины | Raster depth bias обеих карт; 0–16, default 1.25. Компенсирует погрешность self-shadow. Единицы зависят от depth-формата, не метры |
| `Slope depth bias` | Смещение с учётом наклона глубины | Raster slope factor обеих карт; 0–8, default 1.75. Помогает на наклонных поверхностях. Большие значения могут отрывать тень |
| `Spot shadows` | Тень прожектора | Только shadow visibility выбранного spot. Сам spot включается в его `Enabled`; остальные spot и point теней не получают |
| `Shadow-casting spot` | Прожектор, создающий карту | Выбор по `Spot #ID`. На GPU индекс вычисляется заново, поэтому erase не оставляет старую ссылку. Если выбранный удалён — берётся первый оставшийся; при пустом списке `No spots` |
| `Reset shadows` | Сброс настроек теней | Включает оба shadow toggle, h=7, constant=1.25, slope=1.75 и выбирает первый spot. Модели, камера, интенсивности и список света сохраняются |

Карта фиксирована 2048²; near/far не являются настройками UI. `Reset shadows` не включает выключенный источник. Тень spot с outer<0.1° пропускается, чтобы не строить вырожденную проекцию. Широкий конус ограничен 89° полуугла (178° FOV).

## Camera — унаследовано из ЛР3

| Подпись | Перевод / определение | Что меняется и область действия |
|---|---|---|
| `Camera XYZ` | Положение наблюдателя | Камера окна, −50…50 по каждой оси. Не меняет world shadow maps |
| `Camera Euler XYZ` | Углы Эйлера камеры | Повороты в градусах; меняется вид на мир, а не направление источников |
| `Perspective` | Перспектива | Переключает проекцию наблюдателя между перспективной и ортографической |
| `FOV` | Полный вертикальный угол обзора | 10–120°, только при Perspective. Не FOV прожектора |
| `Ortho half height` | Половина высоты кадра | 0.2–20, только при ортографической камере. Не покрытие карты солнца |
| `Reset camera` | Сброс камеры | Только observer camera возвращается к виду на цилиндры и пол |

## Model and material — ЛР3, расширено полом

| Подпись | Перевод / определение | Что меняется и область действия |
|---|---|---|
| `Object` | Выбранный объект | Cylinder 1, Cylinder 2 или Floor; последующие параметры объекта редактируют только его |
| `Material` | Набор текстур | UV grid, Stripes, Panels или Floor (white). Первые два/пол имеют чёрные specular/emissive fallback; Panels — отдельные карты |
| `Special sampling` | Особая выборка albedo | Только выбранный объект переключается на sampling pipeline. Обе lit версии используют настоящие тени |
| `Play sampling effect` | Проигрывать sampling-эффект | Общие часы эффекта; Off останавливает фазу, не выключая shadow passes |
| `Effect speed` | Скорость sampling | 0–4, общая скорость часов эффекта |
| `Effect strength` | Сила sampling | 0–1, общая смесь обычного и изменённого albedo; specular/emissive UV остаются исходными |
| `Effect time` (текст) | Текущая фаза | Показывает общие часы, не редактируется |
| `UV repeat` | Повторение текстуры | 0.25–4, UV scale выбранного объекта |
| `Emissive strength` | Сила самосвечения | 0–4, множитель emissive map выбранного объекта. Чёрная карта остаётся чёрной при любом множителе |
| `Model XYZ` | Положение модели | −10…10; меняет модель во всех проходах, поэтому меняется и настоящая тень |
| `Model Euler XYZ` | Углы Эйлера модели | −360…360°, поворот geometry в main и shadow pass |
| `Scale XYZ` | Масштаб по осям | 0.05–5. Для неравномерного масштаба normal matrix остаётся inverse-transpose |
| `Albedo (linear)` | Цвет материала | Множитель файловой albedo map выбранного объекта |
| `Specular color (linear)` | Цвет зеркального отражения | Умножается на specular map; у чёрного fallback зеркальный вклад нулевой |
| `Shininess` | Степень блеска | 1–256; больше — уже блик Блинна–Фонга |
| `Play animation` | Проигрывать анимацию | Общая анимация цилиндров; пол не двигается вместе с ними |
| `Animation speed` | Скорость анимации | 0.05–4, общий темп траектории/вращения цилиндров |
| `Trajectory radius` | Радиус траектории | 0–3, дополнительное общее перемещение цилиндров по XZ |
| `Vertical amplitude` | Амплитуда по высоте | 0–2, цилиндры поднимаются и опускаются; могут пересекать пол при неподходящих настройках |
| `Vertical frequency` | Частота вертикального движения | 0.25–5, относится к фазе общей анимации |
| `Rotation speed` | Скорость вращения | −180…180° на единицу времени при animation speed=1 |
| `Reset model` | Сброс выбранного объекта | Восстанавливает default выбранного cylinder/floor; также сбрасывает фазы и выключает общую анимацию |

## Ambient and directional — унаследовано из ЛР3

| Подпись | Перевод / определение | Что меняется и область действия |
|---|---|---|
| `Ambient` | Фоновая подсветка | Включает независимый от shadow visibility ambient |
| `Ambient color (linear)` | Цвет фона | Цвет ambient, общий для сцены |
| `Ambient intensity` | Сила ambient | 0–1. Сильный ambient делает тени светлее, не меняя карту |
| `Directional enabled` | Солнце включено | Включает directional direct light; при Off его shadow pass пропускается |
| `Direction (rays travel)` | Направление движения лучей | Вектор −1…1, нормализуется. Изменяет освещение и shadow camera солнца. (0,0,0) → (0,−1,0) |
| `Directional color (linear)` | Цвет солнца | Цвет прямого directional света |
| `Directional intensity` | Сила солнца | 0–4; ноль пропускает его shadow pass |
| `Diffuse contribution` | Диффузная часть | Включает diffuse всех прямых источников, не ambient/emissive |
| `Specular contribution` | Зеркальная часть | Включает specular всех прямых источников, не ambient/emissive |

## Point lights / Spot lights — унаследовано из ЛР3

`Count / capacity / device limit` — фактическое количество источников, ёмкость GPU SSBO и предел устройства. Add отключается при достижении предела. Узлы `Point #ID`/`Spot #ID` открывают настройки конкретного источника; одинаковые локальные подписи не объединяют их состояния.

| Подпись / секция | Перевод / определение | Что меняется и область действия |
|---|---|---|
| `Add point` | Добавить точечный свет | Создаёт включённый источник с новым ID; point shadows в ЛР4 не реализованы |
| `Clear points` | Удалить все point | Удаляет список point, не spot/ambient/directional |
| `Enabled` / Point | Включён | Только выбранный point; маркер может оставаться виден при Off |
| `Position` / Point | Положение | XYZ −20…20, меняет направление и 1/r² затухание |
| `Color (linear)` / Point | Цвет | Только данный point |
| `Intensity` / Point | Интенсивность | 0–100, сила до затухания 1/r² |
| `Remove point` | Удалить point | Удаляет именно открытый источник |
| `Add spot` | Добавить прожектор | Новый ID, включённый spot. Если список был пуст, выбирается для тени |
| `Clear spots` | Удалить все spot | Удаляет список, сбрасывает выбранный ID, spot visibility не семплируется; descriptor остаётся валиден |
| `Enabled` / Spot | Включён | Только данный spot. При Off выбранный не создаёт shadow pass |
| `Position` / Spot | Положение прожектора | XYZ −20…20, меняет перспективную shadow camera выбранного и 1/r² |
| `Direction` / Spot | Ось конуса | Вектор −10…10; нормализуется, ноль → (0,−1,0). Меняет и свет, и карту выбранного spot |
| `Color (linear)` / Spot | Цвет | Только данный spot |
| `Intensity` / Spot | Интенсивность | 0–100; при нуле выбранная карта не обновляется и не применяется |
| `Outer half angle` | Внешний полуугол | 0–89°. За ним cone factor=0; полный FOV shadow projection=2×outer |
| `Inner half angle` | Внутренний полуугол | 0…outer; внутри cone factor=1. Между inner/outer — smoothstep, при равенстве — жёсткая граница |
| `Remove spot` | Удалить spot | Если выбранный удалён, shadow ID переводится на первый оставшийся либо −1 |

Мягкий переход inner→outer относится к освещению конусом. Он не означает мягкую shadow edge: фильтрация карты выбрана NEAREST.

## Light visualization — унаследовано из ЛР3

| Подпись | Перевод / определение | Что меняется и область действия |
|---|---|---|
| `Show light markers` | Показывать маркеры | Unlit кубики в положениях всех point/spot. Не включает свет и не меняет shadow maps |
| `Show spot cones` | Показывать конусы | Линии оси/inner/outer для всех spot, даже выключенных. Не создают тень |
| `Cone display length` | Длина рисунка конуса | 0.2–5, только визуализация. Это не far plane, не радиус света и не дальность карты |

Пол/цилиндры — геометрия сцены. Маркеры/конусы отрисовываются только основным unlit проходом и в shadow pass не участвуют.
