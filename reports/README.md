Итоговый файл для отправки преподавателю: [Салихов Р.Р., М8О-309БВ-24, ЛР1-4](../output/pdf/Салихов_Р.Р._М8О-309БВ-24_ЛР1-4.pdf).

Один PDF содержит один общий титульный лист на ЛР1-4, четыре последовательных отчета, содержание со ссылками, сквозную нумерацию, восемь реальных скриншотов и список источников. Автор: Салихов Руслан Р.; группа: М8О-309БВ-24. Данные института, кафедры и преподавателя взяты из предоставленного образца `3XX_Фамилия_ЛабX.docx`.

Для каждой работы сохранены разделы шаблона: «Условие», «Метод решения», «Результаты», «Выводы». Содержание сверено с четырьмя исходными PDF заданий и фактическими исходниками. В ЛР1 не заявлена реализация нескольких объектов через VkDescriptorSet: показан один цилиндр с push constants и описан принцип расширения. Оценки и отсутствующие персональные сведения не выдумывались.

Оформление: A4, Times New Roman 14 пт, основной интервал 21 пт (1.5), абзац 12.5 мм, поля 30 мм слева, 15 мм справа, 20 мм сверху и снизу. Номера страниц по центру нижнего поля; на общем титульном листе номер не печатается, но он включен в счет. Подписи к рисункам 12 пт, формулы 13 пт. Применены правила оформления ГОСТ 7.32-2017 с сохранением учебной структуры образца; документ не является формальным отчетом о НИР с реквизитами УДК/ГРНТИ.

## Сборка PDF

В Windows используются установленные Times New Roman из `C:/Windows/Fonts`:

```powershell
python -m pip install reportlab Pillow PyMuPDF
python reports/tools/build_report.py
```

`report_content.json` содержит текст, формулы и подписи. `screenshots/` содержит исходные PNG, снятые из клиентских областей работающих программ. `capture_manifest.json` фиксирует режимы и успешные завершения запусков. Для повторного захвата требуются собранные приложения ЛР1-4:

```powershell
python reports/tools/capture_reports.py
python reports/tools/capture_reports.py --labs lab2
```

Программы запускаются в отдельных временных runtime-каталогах. Изоляция устаревших сторонних Vulkan implicit layers задается только для дочернего процесса; явная validation не отключается. Исходники лабораторных при захвате и создании PDF не меняются. `tmp/` содержит промежуточные рендеры и логи и не публикуется.

Проверены все страницы после растеризации, пропорции/границы рисунков, наличие кириллицы и математических глифов, структура оглавления и закладки. Результат машинной проверки и SHA-256 итогового PDF: [verification.json](verification.json).
